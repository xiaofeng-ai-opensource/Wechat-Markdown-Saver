# 方案：不支持的公众号文章链接给出引导提示（长链不转换）

> 状态：**待拍板，未改任何代码** ｜ 日期 2026-11-23（23:22 需求变更）｜ 代码基线 `a6af644`（版本 2.3.0）
> 需求变更：用户裁定「转不了就拉倒，但是要提示；如果确认是微信公众号文章，但是插件又不支持的，提示让去微信公众号里找到对应的文章，找到对应链接，粘贴过来再试」。本方案因此从「支持长链」改为「**不转长链、只给引导提示**」。
> 缩写、代号与三种链接形态统一在**附录 A 术语表**定义；正文使用短词。

## 1. 现状：不支持的链接是「静默失败」

### 1.1 八处硬编码判定

全项目用同一个字符串包含判断「网址里是否有 `mp.weixin.qq.com/s/`」来认定文章页：

| 文件 | 行号 | 所在逻辑 | 现在的表现 |
|---|---:|---|---|
| `popup/popup.js` | 211 | 当前页检查 → 复制入口 | 长链页面点「复制」无效，无解释 |
| `popup/popup.js` | 262 | 网址输入框 `input` 事件 | 长链粘贴后「保存」按钮静默禁用，无任何提示 |
| `popup/popup.js` | 271 | 网址保存按钮点击守卫 | 长链不执行，也不报错 |
| `popup/popup.js` | 384 | 弹窗初始化时检查当前标签 | 显示笼统的「不是公众号文章」，然后禁用全部按钮 |
| `background/service-worker.js` | 178 | 快捷键命令入口 | 只显示一个错误角标 |
| `background/service-worker.js` | 219 | PDF 保存消息守卫 | 后台回一句笼统的「不是公众号文章」 |
| `background/service-worker.js` | 235 | `resolveTabId` 显式标签分支 | 后台标签被静默判无效 |
| `background/service-worker.js` | 240 | `resolveTabId` 当前标签分支 | 同上 |

### 1.2 为什么不做转换

- 短链（`/s/` 后 22 位字符）由微信客户端生成，公开渠道无法由长链参数可靠推导；文章里的 `msg_link` 变量本身也是长链。事实来源见附录 B。
- 长链仍是公众号文章的标准地址，内容脚本其实能抓取；只是本扩展的入口守卫不支持。
- 用户已裁定不转换。因此方案只做一件事：把「静默失败 / 笼统报错」替换成「这是公众号文章但当前格式不支持」的具体引导。

## 2. 需求拆解：两级判断

引导提示只应在「确实是公众号文章、但格式不被支持」时出现，不能把所有无效输入都说成公众号文章。

| 层级 | 判断内容 | 建议依据 |
|---|---|---|
| 第一级 | 是不是公众号相关链接 | 用标准网址解析，域名严格等于 `mp.weixin.qq.com`；路径以 `/s` 开头（最终口径按 D4） |
| 第二级 | 是不是插件支持的格式 | 路径为 `/s/<短码>`，即现有 8 处判断本来接受的形式 |
| 结果 | 第一级为真、第二级为假 | 给出新引导提示 |
| 结果 | 其它情况 | 维持现有的「不是公众号文章」/ 按钮禁用，不误报 |

**一个必须解决的交互细节**：粘贴长链时「保存」按钮当前是禁用的，用户点不了，也就无从触发结果区的提示。因此「提示放在哪」需要先拍板（D2）——行内提示、启用按钮后点击提示，或两者都做。

## 3. 目标与非目标（范围闭合）

### 3.1 目标

- G1：当前页面是公众号文章但格式不支持时，弹窗给出明确引导，而不是笼统的「不是公众号文章」。
- G2：粘贴同源不支持链接时，用户能看到同样的引导，知道该去微信里复制短链。
- G3：非公众号链接、伪装链接仍按原逻辑处理，不误报。
- G4：引导措辞与用户文档口径一致。

### 3.2 非目标（本次明确不做）

- N1：不把长链变成可保存的格式，不做任何长链转短链的转换或第三方服务。
- N2：不改内容脚本的抓取、Markdown 转换、图片下载逻辑。
- N3：不改文件夹授权、写入、zip 降级、状态显示链路。
- N4：不改三份清单的内容脚本匹配规则。
- N5：不处理临时链六小时有效期问题。
- N6：不碰工作区里另一条业务线的五个未提交文件。

## 4. 建议实现

### 4.1 共享分类函数

新增 `shared/wechat-link.js`（沿用 `shared/time.js` 的立即执行函数与 `globalThis.__WMS_LINK__` 暴露方式），只做网址分类，不做转换：

| 导出 | 作用 |
|---|---|
| `classifyUrl(raw)` | 解析失败或非公众号域名 → `other`；支持的短链 → `short`；公众号域名但格式不支持 → `unsupported-wechat` |
| `isArticleUrl(raw)` | 仅 `short` 返回真，替换现有 8 处判断 |

判定用标准网址解析，域名严格比对，避免「`别的域名.example/?u=mp.weixin.qq.com/s/xxx`」这类伪装链接被误认作公众号文章。

### 4.2 接入点

| 文件 | 改动 |
|---|---|
| `popup/popup.html` | 在 `popup.js` 之前加载新模块 |
| `popup/popup.js` | 8 处之外，在初始化与输入事件里根据分类结果展示引导；具体位置按 D2 |
| `background/service-worker.js` | 顶部加载新模块；快捷键与 PDF 分支按 D1 决定范围回传引导文案 |
| 三份清单 | 不改 |

### 4.3 引导文案（建议稿，最终按 D6/D7 拍板）

> 这篇是微信公众号文章，但当前链接格式暂不支持。请在微信里打开这篇文章，点右上角「…」→「复制链接」，把复制的短链粘贴到上方输入框后再试。

英文版同步写入两份 `_locales/messages.json` 与 `shared/i18n.js`（若 D6 选双语）。

### 4.4 文档同步

`docs/使用说明.md`、`help/help.html`、两份 README、`docs/项目工作原理.md` 里关于「长链不支持」的说明，补上「会给出引导提示、如何拿到短链」；不把长链改成「已支持」。

## 附录 A 术语表

| 词 | 含义 |
|---|---|
| 网址 / URL | 统一资源定位符（Uniform Resource Locator），即通常说的网页地址 |
| 短链 | `https://mp.weixin.qq.com/s/<22 位字符>`，由微信客户端生成，是本扩展目前唯一支持的格式 |
| 长链 / 完整链 | `https://mp.weixin.qq.com/s?__biz=...&mid=...&idx=...&sn=...`，公众号文章标准地址，本扩展目前不支持 |
| 临时链 | `https://mp.weixin.qq.com/s?src=11&timestamp=...&signature=...`，搜狗微信搜索产生，约六小时有效 |
| `msg_link` | 公众号文章页面里的全局变量，值是该文章的完整长链 |
| 域名 / hostname | 网址中 `://` 之后、路径之前的主机部分；严格比对可避免伪装链接误判 |
| 路径 / pathname | 网址中域名之后的路径部分，例如 `/s` 或 `/s/abc` |
| 立即执行函数 / IIFE | Immediately Invoked Function Expression，项目共享模块用来隔离内部变量的写法 |
