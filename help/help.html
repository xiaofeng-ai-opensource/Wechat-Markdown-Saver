一、它能做什么

把微信公众号文章（网址形如 mp.weixin.qq.com/s/...）保存成 Markdown（一种轻量标记语言文本格式），也可以把文章里的图片一起下载到本地，或复制成 Markdown 文本、生成 PDF（便携式文档格式）。

三种保存方式互不冲突：每次操作只执行你点的那一种，不会顺带做另外两种。

二、安装

Chrome / Edge

  1. 下载发布包 wechat-md-saver-chrome-x.x.x.zip 或 wechat-md-saver-edge-x.x.x.zip，解压到任意文件夹。
  2. 打开 chrome://extensions/（Chrome）或 edge://extensions/（Edge）。
  3. 打开右上角的「开发者模式」。
  4. 点击「加载已解压的扩展」，选择刚才解压出来的文件夹。

Firefox

  1. 下载 wechat-md-saver-firefox-x.x.x.zip 并解压。
  2. 打开 about:debugging#/runtime/this-firefox。
  3. 点击「临时载入附加组件」，选择解压文件夹里的 manifest.json。
Firefox 不支持文件系统访问接口（File System Access API，浏览器提供的本地目录读写能力），因此不能选择保存文件夹，文章会以 zip（压缩打包文件）形式下载，需要手动解压。

三、第一次使用：先选保存文件夹

  1. 点击浏览器工具栏上的扩展图标，打开弹窗。
  2. 点击弹窗底部的「设置」，或点击文件夹一栏右侧的「更换」，进入设置页。
  3. 在「保存文件夹」处点击「选择文件夹」，授权一个本地目录。

建议选择 Dropbox / OneDrive / iCloud 等同步盘里的目录，方便多设备同步。

  • 如果不选文件夹，保存时会自动降级为下载一个 zip 文件，需要自己解压。
  • 文件夹授权保存在浏览器本地数据库（IndexedDB）中。浏览器重启或授权过期后，设置页会显示「权限已过期」，重新选一次目录即可。
  • 在弹窗里看到绿色文件夹名，表示已设置成功。

五、三种保存方式

操作快捷键图片如何处理结果落在哪里
保存到文件夹Ctrl+Shift+S全部下载到本地，Markdown 里换成相对路径你选的文件夹；失败时降级为 zip 下载
复制到剪贴板Ctrl+Shift+C不下载，保留原始远程链接系统剪贴板
保存为 PDFCtrl+Shift+P保留在排版页面中已选文件夹，或浏览器默认下载目录

1. 保存到文件夹

  • 流程：提取文章 → 下载全部图片 → 在你选的文件夹里新建一个文章目录并写入文件。
  • 生成的 Markdown 文件开头带一段 YAML frontmatter（文件头部的元数据区块），包含 title（标题）、author（作者）、date（发布日期）、source（原文网址）、saved_at（保存时间）五个字段。
  • 图片链接会被替换成相对路径，所以把整个文章目录一起拷走，图片仍然能显示。
  • 图片下载为并发 3 张、每张最多尝试 2 次、单次超时 15 秒。个别图片失败不会中断保存，结果里会显示「N 张失败」，失败的图片在 Markdown 中仍保留远程链接。
  • 成功时扩展图标会短暂显示绿色对勾。

2. 复制到剪贴板

  • 把带同样五个元数据字段的 Markdown 文本复制到剪贴板，不下载图片，图片保留原始远程链接。
  • 适合直接粘贴到 Notion、Obsidian（一款本地笔记软件）或其他编辑器；要注意远程图片链接日后可能失效。
  • 只能在文章页使用：非文章页会提示「不是微信公众号文章」。

3. 保存为 PDF

实际流程与设置页里的旧文案不同，请以下面为准：

  1. 提取文章的原始内容，生成一个 A4 版式、含标题 / 作者 / 日期 / 来源网址的排版页面。
  2. 通过浏览器调试器接口（Debugger API）静默生成 PDF，不需要你点打印。
  3. 如果已选文件夹且写入成功，PDF 直接写进该文件夹；否则下载到浏览器默认下载目录。
  4. 文件名为「文章标题.pdf」。
  5. 如果调试器接口不可用或生成失败，会回退为在文章页打开浏览器打印对话框，此时需要手动选择「另存为 PDF」。

4. 粘贴链接后台保存

  • 在弹窗顶部粘贴含 mp.weixin.qq.com/s/ 的短链，点击「保存」。mp.weixin.qq.com/s?__biz=... 这类长链不会被接受，按钮保持不可点。
  • 扩展会在后台开一个不激活的标签页，等页面加载完成（最多等 30 秒），再等 2 秒让图片地址就绪，然后提取内容并保存，最后自动关闭这个临时标签页。
  • 这种方式只执行「保存到文件夹」，不会复制到剪贴板，也不会生成 PDF。
  • 页面加载超时、内容提取失败或保存失败时会提示错误，并尽量关闭临时标签页。

六、设置项

进入方式：弹窗底部「设置」，或右键扩展图标选择「选项」。

设置可选项实际作用
语言English / 中文实时切换界面文案。未手动设置时跟随浏览器语言，中文环境自动显示中文

默认保存模式保存到本地文件夹 / 复制到剪贴板 / 两者都做当前不生效，详见「九、已知偏差」

快捷键不在这里修改，方法见「八、常见问题」。

七、输出目录长什么样

每次保存会新建一个以「标题_时间戳」命名的子目录。标题中的 / \ : * ? " < > | 会替换为 -，空白会替换为 _，并截断到 100 个字符。

简单模式（默认）

你的文件夹/
└── 文章标题_kx9f2a/
    ├── article.md
    └── images/
        ├── image1.png
        ├── image2.jpg
        └── ...

Obsidian 模式

你的文件夹/
└── 文章标题_kx9f2a/
    ├── 文章标题.md
    └── assets/
        └── 文章标题/
            ├── image1.png
            ├── image2.jpg
            └── ...

也就是说，两种模式的区别有两处：Markdown 文件名（article.md 或「标题.md」），以及图片目录（images/ 或 assets/标题/）。Obsidian（一款本地笔记软件）用户一般选后者，图片链接更不容易失效。

降级成 zip 下载时，压缩包内部布局与所选结构一致，但 Markdown 文件固定叫 article.md，即使选了 Obsidian 模式也一样。

八、常见问题

点按钮没反应，或提示「不是微信公众号文章」

扩展当前只认网址里含 mp.weixin.qq.com/s/ 的短链。mp.weixin.qq.com/s?__biz=... 这类长链（旧式分享链接）会被判成非文章页，连按钮都会被禁用；请改用短链，或在微信里重新复制文章链接。刚安装完扩展时，也需要刷新已打开的文章页。

图片少了，或结果里显示「N 张失败」

单张图片超时 15 秒、最多重试 2 次，微信图片服务器偶发拦截。重新保存一次通常能补齐；失败的图片在 Markdown 里仍保留远程链接。

设置页文件夹显示「权限已过期」，或突然变回「未选择」

浏览器重启或长时间未使用后授权会失效；另外，直写文件夹失败并降级成 zip 下载时，代码也会清掉已设置的标记，看起来就像设置丢了。两种情况重新点一次「选择文件夹」即可。

没选文件夹也能保存吗

能。会自动下载一个 zip 文件，解压后即可得到文章和图片目录。

扩展图标上闪过一个符号

绿色对勾表示成功；叉号表示当前不是文章页，感叹号表示执行出错，问号表示没找到标签页，约 1.5 至 2 秒后自动消失。

想改快捷键

Chrome 打开 chrome://extensions/shortcuts；Edge 打开 edge://extensions/shortcuts；Firefox 打开 about:addons → 齿轮图标 →「管理扩展快捷键」。

点「保存为 PDF」却弹出了打印对话框

说明静默生成没成功，已回退到浏览器打印。在对话框里选择「另存为 PDF」即可。

Firefox 里「选择文件夹」按钮是灰的

正常现象。Firefox 不支持该接口，请用 zip 下载方式。

九、已知偏差（按当前代码如实标注）

1.「默认保存模式」设置当前不生效。 设置页会把选择写入本地存储，但弹窗按钮、快捷键和后台服务都没有读取这个值。无论选哪一项，点「保存到文件夹」仍只写文件夹，点「复制到剪贴板」仍只复制，不会自动变成「两者都做」。请直接点对应按钮或按对应快捷键。
2. 设置页里 PDF 的说明与实际实现不符。 页面写的是「在打印优化页面中打开文章并触发保存为 PDF」，实际是调试器接口静默生成 PDF 并写入文件夹或下载，只有失败时才回退到打印对话框。
3. zip 降级时 Markdown 文件名固定为 article.md。 即使选了 Obsidian 模式，压缩包里也不是「标题.md」；但图片目录仍按所选结构组织。
4. 个别提示文案在两套文案来源里不一致（内置文案表与浏览器本地化文件），界面显示以内置文案表为准，功能不受影响。
5. 网址判定只认短链。 代码里有 8 处用「网址里是否包含 mp.weixin.qq.com/s/」来判断是不是文章页，长链（/s?__biz=...）因此会被误判为非文章，虽然内容脚本其实仍能抓取。应对办法见「八、常见问题」第一条。

十、快捷键一览

快捷键动作
Ctrl+Shift+S保存到文件夹
Ctrl+Shift+C复制到剪贴板
Ctrl+Shift+P保存为 PDF

这三组是扩展建议的默认组合，可以在「八、常见问题」列出的浏览器快捷键管理页面自行修改或关闭。
